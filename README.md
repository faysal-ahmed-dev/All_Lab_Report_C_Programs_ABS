# Data Structures Lab Programs

This folder contains 24 standalone C programs transcribed from *All Lab Report.pdf*. The code is preserved as shown in the PDF; only a short `//` description was added at the top of each source file. Each file has its own `main` function, so compile and run one at a time.

## Open and run in VS Code

Open this folder in VS Code and compile a selected file in the integrated terminal with a C compiler such as GCC:

```sh
gcc 13_bubble_sort_integer.c -o bubble_sort
./bubble_sort
```

On Windows, run `bubble_sort.exe` after compiling.

The file-based examples retain the paths shown in the PDF (`d:\Shouvojit.txt`, `d:\program.txt`, `d:\input.txt`, and `d:\output.txt`). Those examples will only work when the referenced paths and files are available.
